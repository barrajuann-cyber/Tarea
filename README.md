CURSO GITHUB

1. QUE APRENDISTE?

Lo que aprendí de él programa de Git hub, que es un sistema que aguarda y ve los cambios que le damos a una carpeta y podemos ver quien pudo mover lo o desde todo mínimo detalle, asi que de ellos se pueden trabajar varias personas para llegar a un trabajo junto y poder avanzar sin que tengan un error o problema, y aparte es donde se almacenan todos los repositorios donde estemos o donde nos inviten a trabajar


2. COMANDO USADOS
"Todo en minúsculas"

Git init, es el que crea el repositorio en la carpeta 

Git status, es el que muestra los estados de el archivo

Git add. , es el que agrega y ve los cambios 

Git commit -m, es le que aguarda las modificaciones en el historial de la computadora 

Git log, es el que muestra los commits

Git config -- global alias.s, es el que da los atajos

Git tag, es el que pone las etiquetas con nombre en un commit

Git checkout, es el que cambia la rama dentro de otras

Git rama,es el que crea o borra ramas

Git reflog, es el que muestra un historial de lo todo lo que se hizo en el HEAD en total.
